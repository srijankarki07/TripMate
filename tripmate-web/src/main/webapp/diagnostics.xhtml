TripMate: diagnostics

Diagnostics

Integration checks

Runs every check the project has: entity round-trip against PostgreSQL, entity to DTO mapping, CRUD through all five session beans, and the rules that must reject bad input. The first three run inside one transaction each, so they are atomic and leave nothing behind; the rejections run one call per transaction, which is what makes a deliberate failure testable at all.

Jakarta EE 10 · GlassFish 7 · PostgreSQL
